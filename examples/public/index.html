thwip

A small experimental HTTP server and reverse proxy.

Static Serving

Thwip resolved this file from its configured static directory and sent it directly to your browser. No application backend is involved.

Current capabilities

  • Worker-owned listeners with SO_REUSEPORT.
  • epoll on Linux and kqueue on macOS/BSD.
  • HTTP/1.x request-head parsing and exact/prefix routing.
  • Fixed responses and safe, small static files.

Try it
